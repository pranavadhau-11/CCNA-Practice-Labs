CCNA Practice Labs

About This Repository

This repository contains hands-on CCNA networking practice labs using Cisco Packet Tracer. It focuses on building practical networking knowledge through configuration, implementation, and troubleshooting.

Objectives

- Develop practical networking skills.
- Understand networking fundamentals.
- Practice Cisco IOS commands.
- Learn switching and routing configurations.
- Improve network troubleshooting skills.

Tools & Technologies

- Cisco Packet Tracer
- Cisco IOS CLI
- IPv4 Addressing
- Networking Protocols

Topics Covered

No.| Topic| Practice Labs
01| Basic Networking| LAN, Peer-to-Peer, Ping
02| IP Addressing & Subnetting| Static IP, Subnetting
03| Switching| Switch Configuration, MAC Table
04| VLAN & Trunking| VLAN, Access Port, Trunk
05| Routing| Static, Default, Inter-VLAN
06| OSPF| Single Area, Multi Area
07| DHCP & DNS| DHCP, DNS Configuration
08| ACL| Standard ACL, Extended ACL
09| NAT & PAT| Static NAT, Dynamic NAT, PAT
10| Troubleshooting| Connectivity, Ping, Diagnostics

Lab Documentation

Each practical lab may include:

- README.md – Lab explanation and objectives
- Packet Tracer (.pkt) – Network simulation file
- Configuration – Configuration commands and IP details
- Screenshots – Network topology and configuration
- Verification – Ping and command outputs
