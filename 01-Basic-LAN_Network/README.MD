Basic LAN Setup Using Cisco Packet Tracer

Project Overview

Designed and configured a basic Local Area Network (LAN) using a Cisco 2960 switch and four PCs in Cisco Packet Tracer.

Objectives

- Understand basic LAN architecture.
- Configure static IPv4 addresses.
- Establish communication between multiple PCs.
- Verify network connectivity using ICMP Ping.

Tools & Technologies

- Cisco Packet Tracer
- Cisco 2960 Switch
- IPv4 Addressing
- Ethernet

Network Topology

- 1 Cisco 2960 Switch
- 4 PCs
- Ethernet connections

IP Addressing Table

Device| IP Address| Subnet Mask

PC0| 172.16.0.2| 255.255.255.0

PC1| 172.16.0.3| 255.255.255.0

PC2| 172.16.0.4| 255.255.255.0

PC3| 172.16.0.5| 255.255.255.0

Implementation Steps

1. Created LAN topology using Cisco Packet Tracer.
2. Connected four PCs to a Cisco 2960 switch.
3. Configured static IPv4 addresses.
4. Verified connectivity using ping commands.
5. Captured network topology and configuration screenshots.

Verification Commands

ping 172.16.0.3

ping 172.16.0.4

ping 172.16.0.5

Expected Result

All PCs should communicate successfully within the same LAN.
